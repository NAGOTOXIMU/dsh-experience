## 2. 关键前提：先纠正对环境的误判

**这一步决定了后面所有工作的方向。**

| 曾被当作事实 | 真正的事实 | 怎么发现的 |
|---|---|---|
| 桌面版 `DSH_HOME` 是 `apps\dsh-desktop\home` | 是 `C:\Users\汐穆\.dsh` | 读**主进程命令行** |
| 大量插件 `absent`、harness 简陋 | 那是**历史副本**的状态；真实环境 base 完整、DSH 是 `0.2.0-rc.2` | 读真实 profile + 注入的 AGENTS.md 来源 |
| 记忆链"版本不兼容、包无处可指" | 包实测可 `import`；真因是**条目未启用** | 直接 import + 查 registry |

**教训**：判断"哪个目录/哪个状态在生效"，永远先读**运行中进程的参数**。

## 3. 做了什么

### 3.1 记忆统一与分层

- 发现**两套冲突的归档规则**同时被注入（`~/.dsh/AGENTS.md` 新版 +
  `apps\dsh-desktop\home\AGENTS.md` 旧版）。后者停用。
- 把 `AGENTS.md` 从 23 KB 拆成三份，一次会话注入量降 47%：

| 文件 | 内容 | 何时读 |
|---|---|---|
| `AGENTS.md` | 必须无条件遵守的规则 | 每次自动注入 |
| `DSH-ENV.md` | 环境事实、已验证结论、调用限制、踩坑 | 排查/改配置前 |
| `DSH-CAPABILITIES.md` | 能力台账（有哪些工具/skill/插件） | 问能力边界时 |

### 3.2 skill：3 → 10

补入 `office-docx/pptx/xlsx`（应用内置 runtime）、`cordis-plugin-development`、
`editing-cordis-compositions`（preset 自带），并**自写**两个：

- `capability-gap-handling`：能力缺口判定 → 自检 → 结构化上报 → 复验
- `dsh-plugin-sourcing`：寻源 → 兼容/安全审查 → 推荐 → 安装挂载

### 3.3 插件

- **装了 4 个并成功激活**：`@linxin666/dsh-client-ui-skill-explorer`、
  `dsh-plugin-ops-bundle`、`dsh-plugin-marketplace`、`dsh-glass-tweaks`（既有）
- **5 个装了但未激活**：`@ningbainb` 三件套、`dsh-find-plugin`、`dsh-session-recall`
  → 归因见失败模式文档

### 3.4 元认知能力（用户强调的诉求）

写进行为准则：

| 能力 | 落点 |
|---|---|
| 工具存在性预检 | `AGENTS.md` §6 第 8 条 + `capability-gap-handling` §3 |
| **卡住协议（熔断）** | `AGENTS.md` §6.1 + skill §5 |
| GitHub 寻源 | `E:\Tools\gh-dsh-search.py` + `dsh-plugin-sourcing` skill |

**卡住协议的设计立场**：不用"每 N 步 LLM 反思"（会产出正确的废话），
只用**确定性信号**触发：同工具同参数连续 3 次 / 同命令连续失败 2 次 /
8 步无新信息 / 权限被拒。命中即"停 → 报 → 换假设"，同一障碍最多 3 种方案，
**变形重试也算重试**。

### 3.5 工具链

`E:\Tools\` 新增：`gh-dsh-search.py`（npm+GitHub 双线寻源）、
`start-dsh-desktop.ps1`（带代理启动）、`verify-dsh-desktop.ps1`（一键自检）、
`eval-memory-candidates.py` / `check-peers.py` / `probe-memory-import.py`（插件评估）。

并修好两个既有脚本的真实缺陷：

| 脚本 | 缺陷 | 修法 |
|---|---|---|
| `update-nagi-skills.ps1` | 上游目录结构改成 `skills/<分类>/<名字>/` 后**完全失效**（会把分类目录当 skill 名） | 兼容新旧结构 + 默认 DryRun + 同名不覆盖 |
| `archive-push.ps1` | 清理逻辑**把长期备份目录当一次性产物删掉** | 过滤器排除 `^[._]` 开头的目录 |

## 6. 给下一个人的最短建议

1. **别信配置文件，信运行态工具**（`plugin_manager` 的 `fiberPhase`）
2. **装插件前先看它有没有 `dsh.client`** —— 没有就别装，不会生效
3. **别反复 `set_plugin`** —— 对"不激活"无效
4. **没有 `pwsh`，`.ps1` 必须带 BOM**，`$Home` 是只读变量
5. **联网一律先读系统代理**，端口会变
